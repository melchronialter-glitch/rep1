# Continuous Mind Lab V24

**Retrieval ecology without a sovereign archivist.**

Run:

```bash
python -m pytest -q
python lab_v24.py
```

Dependencies: Python, NumPy, PyTest, and Matplotlib.

The lab tests:

- distributed retrieval across semantic, body, relation, and place;
- dormancy and exact return;
- threat retrieval without permanent monopoly;
- recall frequency versus independent grounding;
- dream recombination without compulsory interpretation;
- current-identity filtering versus contradictory memory;
- bounded retrieval-policy suspension;
- visible reconsolidation;
- rejection of a sovereign archivist.

This is a deterministic toy laboratory for causal and governance distinctions.
